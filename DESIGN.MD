# Справочник «Заказ справок и документов» РГСУ — Design System Reference

> **Clean-Density Service Command Interface** — профессиональный сервис заказа документов и справок филиала РГСУ с нейтральным slate-каркасом, первичным сине-голубым акцентным каналом, микро-границами 1px, скруглениями класса Squircle и моноширинной типографикой для кабинетов и счётчиков.

**Theme:** dual-mode (Light / Dark с автоматической поддержкой системной темы и сохранением в `localStorage`).

В основе дизайна лежит концепция абсолютной информационной ясности для студентов и сотрудников: нейтральный slate-каркас поддерживает контент, а насыщенный сине-голубой акцентный канал (Blue 600 / Blue 500) моментально выделяет интерактивные элементы, целевые действия (заказ онлайн) и важные атрибуты (номера кабинетов). Интерфейс избавлен от тяжелых теней в пользу микро-границ 1px (Hairline) и мягких поверхностей.

## 2. Typography

- **Primary Sans Font:** `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **Numeric & Code Font:** `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace` — применяется с классом `tabular-nums font-mono` для номеров кабинетов, счетчиков документов и служебных кодов.

### Type Scale

| Роль | Размер | Вес | Использование |
|---|---|---|---|
| **Display Header** | 24px–30px (`text-2xl sm:text-3xl`) | 700 (Bold) | Главный заголовок сайта |
| **Category Title** | 18px–20px (`text-lg sm:text-xl`) | 600 (Semibold) | Названия категорий справок |
| **Document Title** | 14px–16px (`text-sm sm:text-base`) | 600 (Semibold) | Название типа документа на карточке |
| **Body Microcopy** | 12px–13px (`text-xs sm:text-sm`) | 400 (Normal) | Назначение, отдел, дни выдачи |
| **Numeric Badges** | 12px (`text-xs`) | 600 (Semibold) | Номер кабинета, счётчик «X из Y» |

## 3. Spacing & Squircle Layout

Интерфейс спроектирован по принципу скруглений класса **Squircle**:

- **Карточки документов и модалки:** `16px` (`rounded-2xl`)
- **Кнопки и шапка:** `12px` (`rounded-xl`)
- **Бейджи кабинетов:** `9999px` (`rounded-full`)
- **Чипы требований (паспорт):** `8px` (`rounded-lg`, фирменный рубин `#A91917`)

### Multi-Layer Ambient Shadows (Apple-Style)
Вместо стандартных грубых черных теней используется 2–3-слойная физическая модель рассеянного света в тонах Slate (только для парящих оверлеев и ховера):
- **`shadow-apple-hover`**: Тройной мягкий подъем карточки при наведении (`0 2px 4px`, `0 8px 16px`, `0 16px 32px`).
- **`shadow-apple-modal`**: Глубокое воздушное парение модального окна без резких темных границ.
- **`shadow-apple-tooltip`**: Воздушная тень для всплывающих подсказок.
- **Кнопки действий (Apple Clean Flat)**: строго плоские (`box-shadow: none`) с тактильной реакцией нажатия `active:scale-[0.98]`, исключающие визуальный шум при повторении в сетке карточек.

## 4. Components System

1. **Sticky Header (56px):** Фиксированная шапка с `backdrop-blur-md bg-white/80 dark:bg-slate-950/80` и шириной `max-w-6xl mx-auto`, строго выровненной по сетке с карточками контента. На десктопе содержит логотип и блок квадратных иконочных кнопок `w-9 h-9 rounded-xl` («На главную», «К расписанию» с `Tooltip` и `ThemeSwitcher`). На мобильных устройствах верхняя шапка лаконична (только логотип и бренд).
2. **Mobile Bottom Navigation Bar (Tab Bar):** Фиксированная нижняя панель для мобильных устройств (`fixed bottom-0 pb-safe h-14 backdrop-blur-md`), расположенная в зоне естественного доступа большого пальца (Thumb zone). Включает 3 быстрых действия: «На сайт» (`Home01Icon`), «Расписание» (`Calendar03Icon`) и «Тема» (`Sun03Icon`/`Moon01Icon`).
3. **Hero Header:** Иконка сервиса в синем скверкле (`rounded-2xl bg-blue-50 border-blue-200`) + `h1` + подзаголовок.
4. **Mobile-First Data Density:** Отсутствие громоздких панелей поиска — все 5–7 карточек доступны сразу в первом экране смартфона.
5. **Document Card:** Карточка документа с микро-границами, бейджем кабинета, деталями требований, увеличенной мобильной кнопкой заказа (высота 44px) и кнопкой вызова QR-кода.
5. **QR Code Dialog:** Модальное окно `rounded-3xl` (24px) с концентрическим внутренним контейнером `rounded-2xl` (16px) под QR-код для удобного сканирования со смартфона.
6. **Skeleton Loader:** Анимированные серые заглушки карточек, предотвращающие сдвиг макета (CLS = 0) во время первичной загрузки `documents.json`.

## 5. Do's and Don'ts

### Do
- Использовать `rounded-3xl` для всех внешних контейнеров карточек документов и модалок (согласно формуле концентричности).
- Все цифровые значения (кабинеты, дни, счётчики) оборачивать в `tabular-nums font-mono`.
- Внешние ссылки открывать в `target="_blank" rel="noopener noreferrer"`.
- Сохранять тонкие 1px границы `border-slate-200/80` вместо тяжелых падающих теней.

### Don't
- Не использовать тяжелые тени (`shadow-2xl`) на карточках.
- Не использовать роутеры SPA для ссылок на внешние сайты.
- Не хардкодить данные справок в компонентах — они должны загружаться из внешнего `documents.json`.
