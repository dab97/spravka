# Справочник «Заказ справок и документов» — РГСУ (Минский филиал)

Официальный онлайн-сервис для студентов и выпускников филиала РГСУ в г. Минске. Сервис позволяет быстро найти нужную справку, узнать кабинет и дни приёма, оформить онлайн-заказ или отсканировать QR-код для подачи заявления со смартфона.

Стек: **Vite 6 + React 18 + TypeScript + Tailwind CSS + shadcn/ui**.

## 💻 Требования

Для сборки и локального запуска на вашем компьютере должен быть установлен **Node.js** (версии 18, 20 или новее).

Проверить наличие Node.js можно в терминале (командной строке):
```bash
node -v
npm -v
```
Если Node.js не установлен, скачайте его с официального сайта: [nodejs.org](https://nodejs.org/) (рекомендуется версия LTS).

## 🛠 Первый запуск (локально)

1. Откройте терминал в папке с проектом:
   ```bash
   cd spravka
   ```

2. Установите зависимости (выполняется один раз):
   ```bash
   npm install
   ```

3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
   В терминале появится ссылка вида `http://localhost:3000/`. Откройте её в браузере.

## 📦 Как собрать проект (Билд)

Для подготовки сайта к публикации на сервере/хостинге выполните одну команду:

```bash
npm run build
```

### Что происходит при этой команде?
1. Компилятор TypeScript проверяет код на отсутствие ошибок (`tsc`).
2. Vite собирает и оптимизирует стили, скрипты и картинки.
3. В корне проекта создаётся (или обновляется) папка **`dist/`**.

> [!IMPORTANT]
> **Именно содержимое папки `dist/` и есть ваш готовый сайт!**  
> Саму папку `src`, `node_modules` и файлы конфигурации загружать на хостинг **НЕ нужно**.

## 🚀 Инструкция по загрузке на хостинг (Деплой)

### Шаг 1. Откройте панель управления хостингом или FTP
Подключитесь к вашему серверу через:
- **FTP-клиент** (например, FileZilla, WinSCP, Cyberduck);
- Либо через **Файловый менеджер** в панели хостинга (cPanel, ISPmanager, Beget, TimeWeb и т.д.).

Перейдите в корневую папку сайта (обычно она называется `public_html`, `www`, `httpdocs` или именем домена `spravka.rgsu.by`).

---

### Шаг 2. Скопируйте файлы

> [!WARNING]
> **Частая ошибка:** не копируйте саму папку `dist` целиком!  
> Нужно зайти **внутрь** папки `dist/` на вашем компьютере, выделить **всё её содержимое** и загрузить в корень сайта на хостинге (`public_html`).

#### Что должно оказаться в корне сайта на хостинге:
```text
public_html/ (или папка вашего домена)
├── assets/                  <-- папка с минифицированными css и js
│   ├── index-XXXX.css
│   ├── index-XXXX.js
│   ├── vendor-XXXX.js
│   └── icons-XXXX.js
├── data/                    <-- папка с базой справок
│   └── documents.json       <-- файл со всеми справками, кабинетами и ссылками
├── .htaccess                <-- важный файл настроек Apache (кэширование и MIME-типы)
├── 404.html                 <-- страница ошибки 404
├── error404.svg             <-- иллюстрация для страницы 404
├── favicon.png              <-- логотип-иконка сайта
├── index.html               <-- главная страница сайта с SEO и микроразметкой
├── llms.txt                 <-- файл знаний для ИИ-поисковиков (ChatGPT, Perplexity)
├── og-image.png             <-- картинка-превью для соцсетей (1200x630)
├── robots.txt               <-- правила индексации для поисковых систем и AI
├── site.webmanifest         <-- манифест для мобильных ярлыков (PWA)
└── sitemap.xml              <-- карта сайта для Google и Яндекс
```

> [!NOTE]
> Если на хостинге осталась старая папка `_next` от предыдущей версии сайта — удалите её, она больше не используется.

---

### Шаг 3. Обратите внимание на файл `.htaccess`
Файл `.htaccess` начинается с точки, поэтому на некоторых компьютерах и в некоторых FTP-клиентах он считается «скрытым».
- В **FileZilla**: меню *Сервер* ➔ включите галочку *Принудительно отображать скрытые файлы*.
- В **cPanel**: в верхнем правом углу Файлового менеджера нажмите *Настройки* ➔ отметьте *Показать скрытые файлы (dotfiles)*.

Этот файл **критически важен**: он запрещает браузерам кэшировать `documents.json`, благодаря чему изменения кабинетов сразу видны всем пользователям.

## ✏️ Как менять кабинеты и ссылки без пересборки

**Главное преимущество этой версии сайта:** вам **не нужно** каждый раз запускать `npm run build` и снова загружать сайт целиком, если изменился кабинет, график работы или ссылка!

Файл данных `documents.json` загружается сайтом динамически.

### Пошаговая инструкция для секретаря или администратора:
1. Зайдите в панель управления хостинга в **Файловый менеджер** (или через FTP).
2. Перейдите в папку `data/`.
3. Откройте файл `documents.json` для редактирования (кнопка *«Редактировать»* / *«Правка»*).
4. Найдите нужную справку и измените значение:
   ```json
   {
     "id": 1,
     "department": "Учебная часть",
     "documentType": "Справка о том, что гражданин является обучающимся...",
     "room": "303",                                     <-- измените номер кабинета здесь
     "purpose": "Для предоставления вычетов...",
     "destination": "По месту требования",
     "issueDays": "По мере готовности",                 <-- измените график приёма здесь
     "requirements": "Документ, удостоверяющий личность",
     "link": "https://forms.gle/..."                    <-- ссылка на онлайн-форму
   }
   ```
5. Нажмите **«Сохранить»**.
6. **Готово!** Обновите страницу сайта в браузере (`Ctrl + F5` или `Cmd + Shift + R`) — новые данные появятся мгновенно.

## ❓ Частые вопросы и решение проблем (FAQ)

#### 1. Я загрузил файлы, но открывается пустая белая страница или 404
- **Причина:** Вы загрузили саму папку `dist` целиком, и путь стал `public_html/dist/index.html`.
- **Решение:** Переместите все файлы из папки `dist` непосредственно в корень `public_html/`, чтобы `index.html` лежал прямо в корне.

#### 2. Я изменил кабинет в `data/documents.json`, но на сайте отображается старый
- **Причина 1:** Браузер закэшировал старый JSON (нажмите `Ctrl + F5` для жесткого обновления).
- **Причина 2:** Вы забыли скопировать файл `.htaccess` на хостинг. Убедитесь, что в корне сайта есть `.htaccess`.

#### 3. Как обновить картинку превью для соцсетей (`og-image.png`)?
- В проекте настроен автоматический скрипт:
  ```bash
  npm run generate:og
  ```
  Он сам создаст изображение `1200x630` px с официальным логотипом, градиентом и актуальными надписями. После этого выполните `npm run build` и скопируйте обновленный `dist/og-image.png` на хостинг.

#### 4. Нужно ли пересобирать проект при смене текста или стилей сайта?
- **Да**, если вы правите исходный код в папке `src/` (например, меняете вёрстку, шапку или добавляете новые функции), нужно снова выполнить `npm run build` и перезалить файлы из `dist/` на хостинг.
- **Нет**, если вы меняете только список справок, кабинеты или ссылки — для этого достаточно просто отредактировать `data/documents.json` на сервере.
