# Задача: SEO + GEO/AEO оптимизация сайта «Заказ справок и документов»

> Самодостаточная задача для реализации в будущем (можно отдать нейросети как есть).
> Сейчас сайт вообще не имеет метаданных: `app/layout.tsx` не экспортирует `metadata`,
> нет description, Open Graph, sitemap, robots.txt и структурированных данных.

## Терминология

- **SEO** — Search Engine Optimization: оптимизация под классические поисковики (Google, Яндекс).
- **GEO** — Generative Engine Optimization: оптимизация под генеративные движки (ChatGPT Search, Perplexity, Gemini, Copilot).
- **AEO** — Answer Engine Optimization: синоним/смежный термин — оптимизация под прямые ответы ИИ-ассистентов.
  Цель GEO/AEO: чтобы при вопросе «где заказать справку об обучении в РГСУ» ChatGPT/Perplexity
  цитировали или ссылались именно на этот сайт.

## Этап 1. Базовые метаданные (Next.js Metadata API)

- [ ] В `app/layout.tsx` экспортировать `metadata` (или `generateMetadata`):
  - `title` — например «Заказ справок и документов | [полное название учреждения, РГСУ]»;
  - `description` — 150–160 символов, с ключевыми фразами: «заказать справку об обучении»,
    «справка студенту», «документы по оплате за обучение», «отдел кадров», «бухгалтерия»;
  - `keywords` — опционально (Google игнорирует, Яндекс частично учитывает);
  - `metadataBase` — абсолютный URL сайта (нужен для корректных OG-ссылок);
  - `alternates.canonical`;
  - `openGraph` — `title`, `description`, `url`, `siteName`, `locale: ru_BY` (или актуальная локаль),
    `images: og-image.png` (есть в `public/`, проверить размер 1200×630);
  - `twitter` — `card: summary_large_image`;
  - `robots` — `index: true, follow: true`;
  - `icons` — favicon.png есть в `public/`.
- [ ] Проверить `<html lang>` в layout: должен быть `ru` (сейчас проверить и исправить).

## Этап 2. Техническое SEO

- [ ] `app/sitemap.ts` — генерировать sitemap.xml (статическая страница `/`).
- [ ] `app/robots.ts` — robots.txt, разрешить всё, указать sitemap.
- [ ] JSON-LD структурированные данные (`<script type="application/ld+json">`):
  - `Organization` / `EducationalOrganization` (название, адрес, сайт rgsu.by);
  - `WebPage` + `BreadcrumbList` (если появятся внутренние страницы);
  - можно генерировать из `public/data/documents.json` — там уже структурированные данные.
- [ ] Семантика разметки: один `h1` («Заказ справок и документов»), `h2` у категорий — уже так; проверить.
- [ ] Мета-og-image: убедиться, что `public/og-image.png` имеет 1200×630 и осмысленный текст.

## Этап 3. GEO/AEO — оптимизация под нейросети и ChatGPT

- [ ] **Добавить на страницу (или в footer/About-секцию) блок фактов** в понятном для LLM виде:
  полное название учреждения, адрес, номер кабинета каждого отдела, часы приёма, ссылки на формы.
  Нейросети лучше цитируют страницы с прямым фактическим текстом, а не только UI.
- [ ] **`public/llms.txt`** — текстовый файл со сводкой сайта для LLM-краулеров
  (стандарт формируется: название, описание, ссылки на разделы, ключевые факты).
- [ ] **Единый источник правды**: т.к. все данные в `public/data/documents.json`,
  генерировать JSON-LD и llms.txt из этого же файла (скрипт или серверная функция), чтобы не расходились.
- [ ] Проверить доступность для ИИ-краулеров в robots.ts: не блокировать User-agent'ов
  GPTBot, OAI-SearchBot, ChatGPT-User, PerplexityBot, ClaudeBot, YandexGPT (если хотите попасть в ответы).
- [ ] Разметка FAQ (`FAQPage` JSON-LD): 3–5 вопросов «Как заказать справку об обучении?»,
  «Где находится отдел кадров?» и т.п. — частый формат цитирования в ChatGPT.
- [ ] Регистрация: Яндекс Вебмастер, Google Search Console; для GEO — убедиться,
  что Bing IndexNow подключён (ChatGPT Search использует Bing).

## Этап 4. Контент и локальное SEO

- [ ] Добавить на страницу адрес учреждения и (опционально) карту — важно для запросов «справка + [вуз]».
- [ ] `NAP-консистентность` (Name, Address, Phone) — одинаковое написание названия/адреса везде.
- [ ] Проверить производительность: Lighthouse ≥ 90 (влияет и на SEO, и на GEO).

## Критерии готовности

1. `view-source:` страницы содержит title, description, OG-теги, canonical, JSON-LD.
2. `https://<домен>/sitemap.xml` и `/robots.txt` отвечают 200.
3. `/llms.txt` существует и актуален относительно `documents.json`.
4. Rich Results Test (Google) и Яндекс.Вебмастер не показывают ошибок структурированных данных.
5. Через 4–8 недель после индексации: сайт появляется в результатах Bing/Google и цитируется
   Perplexity/ChatGPT Search по запросам вида «справка об обучении [название учреждения]».
